| **2**             | **Optimal**     | **The entire space behind Dice is Slowed.**                                                                                       |
| 3                 | Acceptable      | Slightly less space behind Dice is Slowed, in exchange for more Ice toward A Link. Use this if you're worried about enemy floods. |
